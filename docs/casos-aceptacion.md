# Casos de aceptación

Los 10 casos del examen, con la prueba automatizada que cubre cada uno y los pasos para verificarlo a mano.

**Antes de las pruebas manuales:** ejecute `php artisan migrate:fresh --seed` para partir de los datos iniciales (ver README, secciones 5 y 6). Todos los usuarios de prueba tienen la contraseña `clinica123`. Guarde las capturas en `docs/evidencias/` con el nombre sugerido.

Las rutas de las pruebas son relativas a `tests/Feature/`. Para ejecutar solo las de un caso:

```bash
php artisan test --filter=NombreDeLaClase
```
